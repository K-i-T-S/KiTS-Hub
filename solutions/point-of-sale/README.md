# KiTS Point of Sale

Modern POS system designed for retail businesses with seamless inventory integration.

## Features

- **Quick Sale Processing**
  - Fast checkout with barcode scanning
  - Multiple payment methods (cash, card, digital)
  - Receipt and invoice generation
  - Customer management integration
  - Real-time inventory updates

- **Payment Processing**
  - Secure payment gateway integration
  - Multi-currency support
  - Tip and gratuity management
  - Refund processing
  - Payment reconciliation

- **Sales Management**
  - Complete order history and tracking
  - Customer order management
  - Return and exchange processing
  - Discount and promotion support
  - Sales analytics and reporting

- **Inventory Integration**
  - Real-time stock updates from sales
  - Product catalog synchronization
  - Automatic stock level adjustments
  - Low stock alerts for POS operations

- **Analytics & Reporting**
  - Real-time sales dashboard
  - Sales performance metrics
  - Transaction analytics
  - Custom report generation
  - Export capabilities (PDF, Excel, CSV)

- **Customer Management**
  - Customer database integration
  - Purchase history tracking
  - Loyalty program support
  - Communication history

## Technology Stack

- **Frontend**: React 18+, TypeScript, Vite, Tailwind CSS
- **Backend**: Supabase (PostgreSQL), Row-Level Security
- **State Management**: React Query, Context API
- **UI Components**: Radix UI, Lucide Icons
- **Styling**: Tailwind CSS with KiTS design system
- **Build Tools**: Vite, ESLint, Prettier
- **Testing**: Vitest, React Testing Library, Playwright

## Quick Start

```bash
# Install dependencies
cd solutions/point-of-sale
npm install

# Configure environment
cp .env.example .env
# Add your Supabase credentials

# Start development
npm run dev
```
